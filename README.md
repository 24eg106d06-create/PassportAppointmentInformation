# Passport Appointment Information

A responsive informational website built with JavaScript, AngularJS, and Node.js. The demo includes general appointment-planning steps, passport preparation reminders, an interactive checklist saved in the browser, and expandable FAQs.

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. In the VS Code terminal, run `npm.cmd start`.
4. Visit `http://localhost:4300`.

There are no npm dependencies. AngularJS and the typeface load from public CDNs, so those assets require an internet connection.

## Scope

This is an independent student project. It is not a government website, does not book real appointments, and does not collect personal application information. Requirements, fees, official links, and appointment availability vary by country and can change. Visitors should confirm all details on the official passport authority website.
